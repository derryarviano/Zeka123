# Zeka123 Flutter

Aplikasi belajar adaptif untuk anak kelas 1–3 SD dengan Fredoka untuk judul dan Nunito untuk isi.

Fitur utama:

- onboarding dan asesmen bergambar;
- dashboard petualangan satu layar;
- empat mata pelajaran dengan 30 level per mapel;
- 1.980 teks soal unik untuk kelas 1, 2, dan 3;
- progres lokal, bintang, musik, koleksi, kreasi, dan ringkasan orang tua;
- target Android, iOS, dan web dari satu codebase Flutter.
